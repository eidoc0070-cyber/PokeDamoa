# PokeDamoa

Bun과 Vite를 기반으로 한 로직 중심의 TypeScript 프로젝트입니다.

## 🛠 사용 기술
* **Runtime & Package Manager**: [Bun](https://bun.sh)
* **Build Tool**: Vite
* **Language**: TypeScript
* **Test**: bun:test & Happy Dom & @happy-dom/global-registrator

## 🚀 명령어
* **Build**: `bun run build`
* **Test**: `bun test`

## ⚠️ 주의사항
* **npm 사용 절대 금지** (반드시 `bun`만 사용할 것)
* **웬만하면 `package.json` 설정을 변경하지 말 것** (현재 환경 최적화 상태)
